# Як опублікувати «Аутдор Активні»

Ця інструкція проведе тебе через публікацію додатка в інтернет — крок за кроком. Не треба бути програмістом. Знадобиться **комп'ютер** (не телефон), близько **1–2 годин** і трохи терпіння.

Після цього додаток буде доступний за постійною адресою, і будь-хто зможе відкрити його з телефону чи комп'ютера.

---

## Що ми зробимо (загальна картина)

1. Створимо безкоштовний акаунт на **GitHub** — там зберігатиметься код.
2. Завантажимо туди файли додатка.
3. Створимо безкоштовний акаунт на **Vercel** — він візьме код і зробить із нього живий сайт.
4. Отримаємо адресу сайту.

Обидва сервіси безкоштовні для твоїх потреб. Платити не доведеться.

---

## Крок 1. Встанови потрібне на комп'ютер

Тобі знадобиться одна програма — **Node.js** (вона потрібна, щоб перевірити додаток перед публікацією; для самої публікації через сайт вона не обов'язкова, але хай буде).

1. Відкрий https://nodejs.org
2. Натисни велику кнопку з написом **LTS** (це стабільна версія).
3. Встанови завантажений файл, натискаючи «Далі».

---

## Крок 2. Створи акаунт на GitHub

GitHub — це «сховище» для коду.

1. Відкрий https://github.com
2. Натисни **Sign up** (Зареєструватися).
3. Введи пошту, придумай пароль і ім'я користувача.
4. Підтверди пошту (прийде лист).

---

## Крок 3. Створи репозиторій (місце для коду)

1. Увійшовши на GitHub, натисни зелену кнопку **New** (або «+» вгорі праворуч → New repository).
2. У полі **Repository name** напиши: `autdoor-actyvni`
3. Обери **Public** (публічний).
4. **НЕ** став галочки «Add README» тощо — лиши все порожнім.
5. Натисни **Create repository**.

Тепер у тебе є порожній репозиторій. GitHub покаже сторінку з інструкціями — не звертай на них уваги, зробимо простіше в наступному кроці.

---

## Крок 4. Завантаж файли додатка

Найпростіший спосіб — через сайт GitHub, без командного рядка.

1. На сторінці свого репозиторію знайди посилання **uploading an existing file** (воно в тексті на сірому фоні). Або відкрий адресу: `github.com/ТВОЄ_ІМʼЯ/autdoor-actyvni/upload`
2. Відкрий папку з файлами додатка на своєму комп'ютері (та, яку ти завантажив разом із цією інструкцією).
3. **Перетягни У ВІКНО БРАУЗЕРА одразу всі файли й папки** з неї:
   - `package.json`
   - `vite.config.js`
   - `vercel.json`
   - `index.html`
   - `.gitignore`
   - папку `src` (з файлами всередині)
   - папку `public` (з іконками)
4. Унизу натисни зелену кнопку **Commit changes**.

> ⚠️ **Важливо:** НЕ завантажуй папку `node_modules` (якщо вона є) — вона величезна й не потрібна. І не завантажуй папку `dist`.

Тепер твій код на GitHub.

---

## Крок 5. Створи акаунт на Vercel і опублікуй

Vercel перетворить код на живий сайт.

1. Відкрий https://vercel.com
2. Натисни **Sign Up** → обери **Continue with GitHub** (увійти через GitHub — так простіше за все).
3. Дозволь Vercel доступ до твого GitHub (натисни **Authorize**).
4. Опинившись у панелі Vercel, натисни **Add New…** → **Project**.
5. У списку репозиторіїв знайди `autdoor-actyvni` і натисни **Import**.
6. Vercel сам розпізнає, що це Vite-проєкт. Нічого не міняй — просто натисни **Deploy**.
7. Зачекай 1–2 хвилини. З'явиться напис **Congratulations** і превʼю сайту.

**Готово!** Натисни на превʼю або кнопку **Visit** — і побачиш свій живий додаток.

---

## Крок 6. Отримай адресу й поділись

Vercel дасть адресу типу `autdoor-actyvni.vercel.app`. Це і є твій сайт — надсилай його людям.

Кожен зможе:
- відкрити його в браузері телефона;
- додати на головний екран як іконку (у меню браузера — «Додати на головний екран»), і він виглядатиме як справжній додаток.

---

## Як оновлювати поїздки (поки без бази даних)

Зараз поїздки «зашиті» в код. Щоб змінити їх:

1. На GitHub відкрий файл `src/App.jsx`.
2. Натисни олівець (✏️ Edit) угорі праворуч.
3. Знайди розділ `const TRIPS = [` — там усі поїздки.
4. Відредагуй текст (за зразком наявних поїздок).
5. Унизу натисни **Commit changes**.
6. Vercel **автоматично** оновить сайт за 1–2 хвилини.

> Це трохи незручно, але для 3–4 поїздок на місяць — цілком робочо. На наступному етапі можна підключити базу даних, щоб додавати поїздки прямо в додатку, і вони зберігалися самі.

---

## Що далі (Етап 2 — коли будеш готовий)

Коли сайт запрацює й ти освоїшся, можна додати:

- **База даних (Supabase)** — щоб поїздки, які ти додаєш через адмінку, зберігалися й з'являлися в усіх. Тоді редагувати код не треба.
- **Автопереклад (DeepL)** — щоб вміст поїздок перекладався сам на 3 мови. Безкоштовно для твоїх обсягів.
- **Жива погода (Open-Meteo)** — справжній прогноз замість демо. Безкоштовно.
- **Розклад Deutsche Bahn** — автоматичні часи поїздів.

Усе це — окремий етап. Скажи, коли захочеш ним зайнятись.

---

## Якщо щось пішло не так

- **На Vercel помилка збірки (Build failed)?** Найчастіше — не всі файли завантажились на GitHub. Перевір, що є `package.json` і папка `src` з файлом `App.jsx`.
- **Сайт відкривається, але порожній/білий?** Перевір, що завантажив папку `src` повністю (з `main.jsx` і `App.jsx`).
- **Не бачиш репозиторій у Vercel?** Натисни «Adjust GitHub App Permissions» і дай доступ до нього.

Будь-яке питання — став його, розберемось разом.
